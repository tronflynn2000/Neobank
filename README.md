# Neobank
This project is a streamlined banking application featuring core digital banking functionalities. I designed and integrated a robust PostgreSQL database with a custom-built backend. Throughout the development lifecycle, I have applied industry-standard software engineering principles, including Clean Code, continuous refactoring, and Design Patterns to ensure scalability. To guarantee reliability, the codebase will be supported by a comprehensive unit testing suite.

Moving forward, I am integrating advanced workflows such as AI-assisted programming, specifically adopting Spec-Driven Development (SDD) to streamline the development process.
